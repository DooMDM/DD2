# STALKER 2 Fire Save Repair · 0.6.3

Бесплатная программа для Windows x64: находит сохранения с постоянным огненным эффектом и исправляет проверенный случай без отката прогресса. Один EXE, без установки, подписок, оплаты, регистрации и дополнительных скачиваний. Работа полностью офлайн.

Это ремонт конкретного бага с FireBreathDamage, не универсальное удаление всех отрицательных эффектов. Само наличие огня в сейве ещё не доказывает, что он застрял: можно сохраниться внутри опасной зоны.

При каждом запуске выбран **English**. Переключатель **EN / RU** справа вверху меняет язык кнопок, результатов, причин блокировки и подтверждений без повторного сканирования. Системные окна выбора файлов используют язык Windows.

В 0.6.3 окно оформлено ближе к странице медиа: отдельные тёмные карточки для источника сейвов, результатов сканирования и деталей выбранного сейва. Кнопка сканирования находится сразу рядом с выбором папки, хвосты кнопки запуска игры и технические значки убраны, переключение English/Russian работает для кнопок, результатов и подтверждений.

## Как пользоваться

1. Запустите `Stalker2FireSaveRepair.exe`.
2. Выберите папку `Data` внутри `SaveGames` (или саму `SaveGames`). Типичный путь Steam: `%LOCALAPPDATA%\Stalker2\Saved\STEAM\SaveGames\Data`.
3. Нажмите **Scan folder / Сканировать**. Для отдельного файла есть **One save / Один сейв**. Сканирование ничего не меняет.
4. Выберите нужный сейв со статусом **Fire · ready to repair / Огонь · можно исправить**. Сверьте имя и дату; полный путь и SHA256 — в Details / Подробнее.
5. Закройте игру, выберите, нужен ли бэкап, и нажмите **Repair selected save / Исправить сейв**. Подтвердите замену именно этого файла.
6. Загрузите тот же слот в игре и проверьте здоровье вне аномалии, с выключенным бессмертием / трейнером.

## Галочка Create backup / Создать бэкап

**Выбранный сейв всегда заменяется на месте.** Галочка отвечает только за бэкап:

- Включена (по умолчанию): сначала создаётся проверенная копия оригинала, затем файл заменяется.
- Выключена: файл заменяется **без резервной копии**, после явного предупреждения. Скрытого постоянного бэкапа нет; отменить замену через программу нельзя.

После успешного исправления ничего вручную переносить не нужно. Имя файла, задания, инвентарь и остальные данные остаются от выбранного сейва. Донорский сейв не используется, другие слоты и `CampaignsSave.sav` не меняются.

Отчёт и, при включённой галочке, `original/<имя сейва>.sav` сохраняются в уникальной подпапке `FireSaveRepair-results` рядом с исходным файлом. Кнопка **Report / backup — Отчёт / бэкап** открывает результат. При выключенной галочке там только отчёт, без SAV-копии. Для атомарной записи используется временный файл; это не бэкап.

Если возникла проблема и бэкап был включён: закройте игру и верните одноимённый файл из `original` на прежнее место. Без бэкапа такого отката нет. Не восстанавливайте всю папку поверх более новых сейвов. Перед ремонтом приостановите облачную синхронизацию: она может позже вернуть старые файлы.

## Статусы

| Статус | Значение |
|---|---|
| Огонь · можно исправить | Найден огненный эффект и проверенная структура связанного урона. |
| Огонь · правка заблокирована | Огонь найден, но есть другой урон, неизвестные эффекты либо отличающиеся параметры. Причина приведена внизу. |
| Эффект не найден | FireBreathDamage не найден. Это не проверка всех возможных проблем со здоровьем. |
| Не удалось проверить | Не поддерживается формат, нарушена контрольная сумма или нет доступа. Такой сейв нельзя считать здоровым. |

Например, одновременный `RadiationLevel10Damage` блокирует ремонт: безопасное разделение общей суммы огня и радиации не подтверждено. Программа не стирает другие виды урона.

В списке — **имена и даты изменения файлов**, не названия заданий, игровое время или картинки. «Только найденный огонь» скрывает остальные строки, включая ошибки; счётчик непроверенных файлов остаётся виден. Подпапки резервных копий не сканируются рекурсивно.

## Проверки и ограничения

- До распаковки проверяется контрольная сумма; после ремонта выполняются повторная распаковка и побайтовое сравнение с ожидаемым результатом.
- Удаляется одна 36-байтовая запись FireBreathDamage, 8-байтовый агрегат Damage и обнуляется только соответствующая добавка урона. Счётчики и указатель словарей обновляются; остальные байты сохранены.
- Полный формат сейва разобран не целиком. Неоднозначный, неизвестный или небезопасный случай блокирует правку.
- Не используйте с модами, меняющими типы эффектов. Каталог совместимости относится к 2.0.4; тип, изменённый модом под тем же именем, нельзя надёжно определить по сейву.
- Лимиты: 128 МиБ на SAV, 256 МиБ после распаковки, 500 файлов в выбранной папке. Другие версии, WGS-контейнеры и произвольные повреждения не поддерживаются.
- Программа не меняет моды и не передаёт сохранения в сеть. Отчёт содержит имя файла и контрольные суммы.
- Это неподписанная любительская сборка. Не отключайте защиту Windows ради запуска; при сомнении проверьте исходники.
